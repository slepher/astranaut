# Macro Expansion Spec Delta

## MODIFIED Requirements

### Requirement: External Macro Expansion Uses A Uniform Environment

External macro expansion SHALL use a uniform macro environment containing all imported external macro modules instead of expanding one imported module at a time.

#### Scenario: Later import generates earlier import call

- **GIVEN** a module imports `macro_a` before `macro_b`
- **AND** `macro_b` expands into `macro_a:foo(...)`
- **WHEN** macro expansion runs
- **THEN** the generated `macro_a:foo(...)` call is expanded

#### Scenario: Earlier import generates later import call

- **GIVEN** a module imports `macro_a` before `macro_b`
- **AND** `macro_a` expands into `macro_b:foo(...)`
- **WHEN** macro expansion runs
- **THEN** the generated `macro_b:foo(...)` call is expanded

### Requirement: Preserve Outer And Inner Ordering

The uniform macro environment SHALL preserve the existing traversal ordering where `order = outer` expands during pre traversal and `order = inner` expands during post traversal.

#### Scenario: Outer macro sees raw child syntax

- **GIVEN** an outer macro wraps another macro call
- **WHEN** macro expansion runs
- **THEN** the outer macro can receive the unexpanded child syntax

#### Scenario: Inner macro sees expanded child syntax

- **GIVEN** an inner macro wraps another macro call
- **WHEN** macro expansion runs
- **THEN** the child macro is expanded before the inner macro receives its argument

## ADDED Requirements

### Requirement: Local Macro Source Snapshot Is Locked

Local macro functions and related functions SHALL be expanded only with the external macro environment before compiling the temporary local macro module, and SHALL be skipped by final expansion.

#### Scenario: Final expansion skips local macro definitions

- **GIVEN** a function is part of the local macro source snapshot
- **WHEN** final expansion runs with external and local macros
- **THEN** that function is not modified by the final macro environment

### Requirement: Final Expansion Uses External And Local Macros

Final expansion SHALL use a uniform macro environment containing both external macros and loaded local macros.

#### Scenario: Local macro generates external macro call

- **GIVEN** a local macro expands into an external macro call
- **WHEN** final expansion runs
- **THEN** the generated external macro call is expanded

### Requirement: Max Depth Limits Expansion Chains

`max_depth` SHALL limit the depth of a macro expansion chain, including chains that pass through different macros generated by previous expansion results.

The default `max_depth` SHALL remain `100`.

#### Scenario: Global max depth stops generated macro chain

- **GIVEN** a module sets `-macro_options([{max_depth, 10}])`
- **AND** a macro expands into another macro call recursively
- **WHEN** macro expansion exceeds 10 chained expansions
- **THEN** compilation reports `max_macro_expansion_depth_exceeded`

#### Scenario: Independent macro calls do not share one max depth budget

- **GIVEN** a module contains multiple independent macro calls
- **WHEN** each expansion chain is within `max_depth`
- **THEN** compilation succeeds
